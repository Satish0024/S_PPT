# Saturna Participant Portal

React app for U.S. plan participants. Built with Vite, React Router, Lucide icons, and Chart.js.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

## Pages

- Dashboard (`/`) with five participant scenarios
- Enrollment (`/enrollment`) and Auto Increase (`/enrollment/auto-increase`)
- Investment Portfolio (`/portfolio`)
- Enrich learning portal (`/enrich`)
